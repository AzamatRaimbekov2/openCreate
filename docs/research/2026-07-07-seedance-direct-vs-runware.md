# Build vs Buy: видеогенерация Seedance — ByteDance напрямую vs Runware

**Контекст:** openCreate — pre-launch, 0 пользователей, единственная интеграция — Runware (REST, один API-ключ, ассеты автоматически копируются в собственный сторедж). Ритейл-цена «standard» видео-тира: 35 кредитов = $0.35 за 5s.

**Важно про единицы:** ByteDance (BytePlus/Volcengine) биллит **токенами**: `tokens = width × height × 24fps × duration / 1024` → 720p = 21 600 ток/с, 1080p = 48 600 ток/с. Runware/Replicate биллят **за секунду вывода**, fal.ai для Seedance 1.0 — за токены, для 2.0 — за секунду. Всё ниже пересчитано в цену за клип.

## 3. Не-ценовые факторы

**Фрикция подключения ByteDance:**
- **BytePlus (международный)** — умеренная: email + карта (Visa/MC/Amex/Maestro/PayPal, международные карты ок), без минимального депозита и без бизнес-верификации для базового API; ~195 стран. Но: для Seedance 2.0 нужны предоплаченные resource packs (управление балансом пакетов = доп. операционка); есть free-токены (⚠️ ~2M — цифра третьих сторон).
- **Volcengine (CN)** — фактически недоступен: +86 телефон, real-name верификация с китайским ID, счета в CNY. Не вариант.

**Лимиты и надёжность:**
- Direct: жёсткие лимиты на аккаунт — **10 одновременных задач / 600 RPM**, 429 при превышении; публичного SLA на видеогенерацию нет. Runware абстрагирует лимиты («better rate limits», платформенное масштабирование) и биллит только успешные запросы.
- Direct API — асинхронный task-based (create/poll + callback_url), кастомная схема (не OpenAI-совместимая), генерация 30–120 с. **URL видео умирает через 24 часа** — обязательная выгрузка в свой сторедж. У Runware ассеты уже автоматически попадают в ваш сторедж — этот кусок пайплайна пришлось бы строить заново.

**Стоимость интеграции второго провайдера (у нас Runware-shaped клиент + сторедж):**
Новый клиент с иной формой API: создание/поллинг задач с backoff, вебхуки, выгрузка видео в сторедж до истечения 24h, маппинг ошибок/статусов, учёт токенов из поля `usage`, менеджмент resource packs, secrets, мониторинг, роутинг «какой провайдер для какой модели». Реалистично **3–5 дев-дней на MVP + постоянная поддержка двух провайдеров** (две биллинг-модели, два набора инцидентов). Плюс абстракция над провайдерами, которой сейчас нет.

**Vendor lock:**
- Остаться только на Runware — лок на агрегатора, но мягкий: одна интеграция даёт весь мультимодельный каталог, смена модели — смена AIR-ID.
- Уйти только в BytePlus — лок на ByteDance + гео-регуляторный риск (доступность моделей различается по странам) + лок на их биллинг (пакеты).
- Оптимум — тонкий provider-слой в своём API: тогда второй провайдер добавляется, когда это оправдано цифрами, а не заранее.

## 4. Вердикт

**Порог целесообразности прямого BytePlus.** Экономия существует практически только на Seedance 2.0/2.0 Fast: ~$0.34 и ~$0.29 на клип 5s 720p. При цене интеграции ~$1.5–3k (работа + ops):

- **< 1 000 клипов 2.0/мес** (< ~$336/мес экономии) — не окупается, чистый минус с учётом поддержки.
- **~2 000–5 000 клипов 2.0/мес** — зона рентабельности: окупаемость за 1–4 месяца. Разумный триггер для начала интеграции.
- **≥ 10 000 клипов 2.0/мес** (~$3.4k/мес экономии) — прямой канал очевидно выгоден; но сначала запросить у Runware volume discount (они существуют, sales-only) — скидка ~40% возвращает паритет без второй интеграции. Помнить про лимит direct: 10 одновременных задач — на 10k+/мес при пиках может понадобиться повышение квоты (возможность не подтверждена).
- Если продукт живёт на **1.5 Pro / 2.0 Mini / 1.0 Pro Fast** — прямой канал **не имеет смысла ни при каком объёме**: паритет или Runware дешевле.

**Рекомендация для openCreate сейчас (pre-launch, 0 пользователей): остаться на Runware.** При нуле трафика экономия равна нулю, а вторая интеграция — это реальные дни работы и постоянная операционка. Runware к тому же самый дешёвый агрегатор по Seedance 2.0. Сделать сейчас стоит три дешёвые вещи: (1) заложить тонкий provider-интерфейс в видео-клиенте, чтобы BytePlus добавлялся за дни, а не недели; (2) пересмотреть standard-тир $0.35/5s — он убыточен на Seedance 2.0 у любого провайдера, тир должен бекаться 1.5 Pro/Mini/Pro Fast либо стоить дороже; (3) поставить триггер: устойчивые ~1–2k клипов Seedance 2.0/мес → параллельно запросить скидку у Runware и открыть аккаунт BytePlus (карта + free-токены позволяют провалидировать интеграцию почти бесплатно).

**Честно о конфликтах и непроверенных цифрах:** ставка Runware $0.16 — это за секунду (миф «$0.16/клип» — строка примера для 1-секундного клипа, подтверждено тремя первоисточниками); страница Runware 1.0 Pro (~$0.78/генерацию) конфликтует с доками ($0.484/5s 1080p) — конфиг примера неизвестен; 1080p у Seedance 2.0 direct не подтверждён; BytePlus USD-цены на 1.5 Pro и 2.0 Mini не опубликованы (только консоль); $1.0/M за 1.0 Pro Fast — цифра третьей стороны; PAYG-ставка 2.0 после пакетов не подтверждена; данные Kie.ai не верифицированы; размеры free-кредитов везде разнятся; CNY→USD взят по ~7.1.
