# ADR: Seedance 2.0 идёт через Segmind

- **Статус**: accepted (владелец, 2026-08-02)
- **Заменяет**: часть [seedance-direct-bytedance](./seedance-direct-bytedance.md) — тот ADR перевёл модель с прямого ByteDance на DeepInfra; этот переводит её дальше, на Segmind
- **Область**: только `seedance-2-0`. Kling, Veo, Wan 2.7, PixVerse, MiniMax остаются на Runware

## Контекст

Вопрос «какой канал Seedance дешевле» несколько раз получал уверенный, но неверный
ответ. Причина не в арифметике, а в источнике: все ответы брались из прайсов, а
прайсы врут двумя способами.

**Первый — ловушка двух колонок.** Каждый провайдер публикует две цены на разрешение:
`with video input` (дешевле за секунду, но счёт идёт по вход+выход) и `no video input`
(дороже за секунду, только по выходу). openCreate шлёт текст или картинку и **никогда
видео**, значит всегда на дорогой строке. Сравнительные обзоры цитируют дешёвую — и
приходят к обратному выводу. Ловушка сработала на **всех пяти** изученных каналах:
DeepInfra ($4.3 против $7/M), kie.ai, BytePlus, fal, Atlas Cloud.

**Второй — прайс расходится со счётом.** Прайс DeepInfra обещает $7.00/M для 720p.
Реальное списание за клип 15с/720p: **$2.50173 при 324 900 токенах = $7.70/M**, то есть
на 10% больше заявленного. Обнаружено только потому, что провайдер возвращает свою
сумму в ответе (`inference_status.cost`).

## Инструмент, который сделал сравнение возможным

Формула токенов, опубликованная OpenRouter:

```
токены = ширина × высота × длительность × 24 / 1024
```

Проверена на реальных счетах **дважды**: DeepInfra — расхождение 0.28%, Segmind — 0.33%.
Она приводит несравнимое к общей шкале: одни провайдеры считают по секундам, другие
по токенам, и только ставка за миллион позволяет их сопоставить.

Следствие: цену любого разрешения теперь можно посчитать заранее, не тратя денег.
Прогноз для 15с/1080p на Segmind был $5.10, списали **$5.12**.

## Результат обзора (2026-08-02)

| Канал | Ставка $/M | 15с / 1080p | Источник |
|---|---|---|---|
| **Segmind** | **$7.02** | **$5.12** | **живой счёт** |
| DeepInfra | $7.70 | $5.61 | живой счёт |
| BytePlus напрямую | $7.70 | $5.61 | их документация + пакет $29.40 |
| Higgsfield | — | $6.34 | 135 кредитов × $0.047 |
| kie.ai | ~$10.49 | $7.65 | их таблица |
| fal / Replicate | ~$14 | $10.23 | их прайс |

**$7.00/M — это пол**: базовая ставка самого ByteDance для строки без видео. Segmind,
OpenRouter и ofox.ai стоят ровно на нём. Segmind вдобавок держит плоские $7.00/M и на
1080p, где производитель берёт $7.70 — то есть 1080p там дешевле, чем у первоисточника,
и без невозвратного пакета за $30.10.

## Решение

`seedance-2-0` маршрутизируется на **Segmind**:

- `air: 'segmind:seedance-2.0'` — синтетический префикс, адаптер его срезает, остаток
  равен последнему сегменту пути их эндпоинта
- `provider: 'segmind'`, модель скрыта из `/api/catalog` без `SEGMIND_API_KEY`
- цепочка failover: **segmind → deepinfra → bytedance**

DeepInfra не удалён, а сдвинут на второе место: он на 9% дороже, но проверен, и переход
на него стоит центы против отказа целиком. ByteDance третий — он отвечает только после
покупки пакета, до тех пор падает мгновенно и ничего не стоит.

## Что это даёт

Экономия **$0.49 на ролике** 15с/1080p, то есть $49 на сотне. Цифра измеренная, не
прайсовая.

Важнее денег — **предсказуемость**: Segmind единственный из пяти, чей прайс совпал со
счётом. Прогноз на 0.4% означает, что цену продукта можно планировать.

## Чем платим

**Segmind не возвращает сумму списания в ответе.** У DeepInfra есть
`inference_status.cost`, у kie.ai `creditsConsumed` — у Segmind ничего. Поэтому
`costUsd` в шве остаётся `null`, а маржинальные дашборды по этому каналу считать
нечем. Сверка только вручную по их кабинету.

Сознательно НЕ подставляем собственную арифметику: `costUsd` во всём проекте означает
«сколько списал провайдер», и оценка на этом месте сделала бы её неотличимой от чека.
Для явных оценок есть отдельный `estimateCostUsd`.

**Результаты живут 1 час** (у kie.ai — 24 часа). Воркер обязан скачать файл сразу.

**Валидация происходит ПОСЛЕ постановки в очередь.** `200` на submit не означает, что
тело корректно — невалидный запрос всё равно получает `request_id`. Обнаружено
случайно: зонд, который должен был отвергнуться валидацией, ушёл в очередь.

## Незакрытый пробел

Хост, с которого Segmind отдаёт готовый mp4, **неизвестен и не добавлен в SSRF-аллоулист**.
Для страниц `/compare-video` и `/verify` это не мешает — браузер играет ссылку напрямую.
Для продовой генерации через `/api/generations` обязательно: `storage.saveFromUrl`
отклонит скачивание. Хост вскроется первым же прогоном (адаптер пишет сырой конверт в
лог), после чего добавляется по образцу `KIE_ASSET_HOST` в `config.ts`.

## Почему Segmind не стал единственным провайдером

Проверено прямыми запросами: у них **нет Kling, Veo, Wan и PixVerse** (404 на странице
цен). Это четыре из восьми наших видеомоделей. Их специализация — Seedance, Grok
Imagine, MiniMax H3, Gemini Omni, Luma Ray плюс аватарные и утилитарные модели.

Шов `VideoProvider` именно для этого и строился: каждая модель идёт своим маршрутом.

Побочная находка: **Seedance 2.0 Mini по $3.50/M** ($0.0756/с на 720p) — ровно вдвое
дешевле старшей модели, кандидат на черновые прогоны шотов.

## Отвергнутые варианты

**Volcano Engine (материковый volcengine.com)** — ставка ¥46/M ≈ $6.81/M, самая низкая
из найденных. Отвергнут: регистрация требует номер **+86**, зарубежные не
поддерживаются (их собственный FAQ). Выигрыш против Segmind составил бы 2.6%.

**BytePlus напрямую** — те же $7.70/M, что у DeepInfra, плюс невозвратный пакет $29.40
на 90 дней. Окупается только на 4K, где он вдвое дешевле реселлеров.

**ofox.ai** — равен Segmind на 1080p ($7.00/M), дороже на 720p. Плюсы: постоянные
ссылки на файлы и OpenAI-совместимый протокол. Минус, который перевесил: любая
комбинация параметров вне их таблицы тарифицируется по **$1.70/с** — впятеро дороже
1080p. Один незнакомый ключ в запросе превращает ролик из $5.10 в $25.50.

**Higgsfield** — $6.34 за ролик по топап-цене. По подписке ULTRA выходит $4.46, но
лимит 3000 кредитов = 22 ролика в месяц, дальше топап. Это платформа, а не API: платишь
за пресеты и студии, которые у нас свои.

## Проверки

Каталог, маршрутизация, failover и оба сравнительных набора обновлены. API 862 теста,
веб 929, ESLint чисто. Ошибки типов в `canvas/service.ts` и падение `PromptNode` — чужая
незакоммиченная работа по Canvas, к этой правке отношения не имеют.
